# Перетини UA ↔ сусідні країни → «Калькулятор IMPORT_EXPORT.xlsx»

## Що робить
`update_crossings.py` бере результати добових аукціонів із JAO (той самий
ендпоінт, що й кнопка «Export auction») і записує ціну в листи «Прайс Перетину …»:

| Напрям JAO | Лист |
|---|---|
| UA-HU / HU-UA | Прайс Перетину UA-HUN / HUN-UA |
| UA-SK / SK-UA | Прайс Перетину UA-SK / SK-UA |
| UA-PL / PL-UA | Прайс Перетину UA-PL / PL-UA |

Правило: Offered capacity (колонка H в експорті) > 0 → Price (колонка J), інакше `#DIV/0!`.
Година 1 = 00:00–01:00 CET (як у JAO); на 25-годинну добу заповнюється й колонка AA.
Числа пишуться як справжні числа: в українській локалі Excel покаже їх із комою.

Скрипт змінює тільки XML цих аркушів, тож графіки, таблиці й форматування
лишаються як були. При відкритті Excel перерахує формули.

## Основний режим: запис прямо в Google Таблицю
```
pip install -r requirements.txt
python update_crossings.py --gsheet
```
Скрипт пише в https://docs.google.com/spreadsheets/d/1h3-Q_c4cIHo4waNnQulKN9Vm8K_4rbbURjZ5b-2UJL8
(«Калькулятор IMPORT_EXPORT (1)»), у листи «Прайс Перетину …».
Для кожного листа знаходить останній заповнений день і дописує дні від наступного до завтра.
Дата пишеться в A, `=TEXT(A;"DDD")` у B, ціни в C..Z (25-та година в AA), `#DIV/0!` записується як справжня помилка.
Доступ налаштовується так само, як описано нижче (`credentials.json`). На OAuth consent screen додайте ще й Google Sheets API
(Library → Google Sheets API → Enable). Під час першого запуску відкриється вхід, токен збережеться в `token_sheets.json`.

## Ціни РДН (листи «РДН UA/SK/PL/HUN/MD/RO»)
```
python update_rdn.py            # дописує всі листи від останнього заповненого дня до завтра
python update_rdn.py --dry-run  # показати, що буде записано, нічого не змінюючи
```
| Лист | Джерело | Що пишеться |
|---|---|---|
| РДН UA | ОРЕЕ, oree.com.ua (грн) | AE..BB: київські години; C..Z: формули CET, як у таблиці |
| РДН SK | OKTE, isot.okte.sk (EUR) | AB..: 15-хв ціни; C..Z: `=AVERAGE` по 4 чвертях |
| РДН PL | energy-charts.info (дані ENTSO-E/SDAC) | так само, як SK |
| РДН HUN | energy-charts.info | C..Z: годинні середні (CET) |
| РДН RO, РДН MD | OPCOM, opcom.ro | C..Z: годинні середні за інтервалами OPCOM (MD = ціни RO, як у таблиці) |

Перевірено на історії таблиці за 01.08–30.09.2026: PL, HU, UA, RO, MD збіглися повністю,
SK — 44 з 54 днів до кожної 15-хвилинки (18–27.08 у таблиці вставлені годинні значення замість 15-хв).

## Щоденний запуск (автоматично)
1. Один раз налаштуйте доступ до Google (розділ про `credentials.json` вище).
2. Запустіть `install_task.bat`. Він створить завдання Windows «KT_bot Import Export» щодня о 13:00.
3. Завдання запускає `run_daily.bat`, а той запускає `python run_all.py`:
   - перша спроба о 13:00, далі повтор кожні 20 хв (JAO, eap-office, РДН), поки в таблиці не буде завтрашньої дати
     для всіх 10 перетинів і всіх 6 цін РДН (крайній час 18:00);
   - коли все записано: оновлюється сайт (`docs/`, GitHub Pages), у Telegram (гілка 2159) іде звіт, і скрипт завершується;
   - кожного разу перевіряються останні 10 днів, і пропущені дні дописуються;
   - лог пишеться в `log.txt`.

### Коли з'являються дані (київський час; Київ завжди на 1 год попереду CET)
| Дані | Джерело | Публікація D+1 |
|---|---|---|
| Перетини UA↔HU, UA↔SK, UA↔PL | JAO | ставки до 11:10, попередні 11:20, остаточні ≈11:22–11:50 |
| РДН SK, PL, HU, RO (MD) | SDAC → OKTE / energy-charts / OPCOM | попередні 13:45, остаточні 13:57; на сайтах ≈14:00–14:30 |
| РДН UA | ОРЕЕ | орієнтовно після 13:00 (точний час не підтверджено) |
| UA↔RO, UA↔MD (eap-office) | Укренерго | невідомо: сайт недоступний з-за кордону |

## Запуск з xlsx на Google Drive (старий файл)
```
pip install -r requirements.txt
python update_crossings.py --drive
```
Скрипт завантажує файл https://docs.google.com/spreadsheets/d/1tZJZBoDH8CLQu0RzTIFds8PLgK2E9Wso ,
дописує дані й заливає результат **новою версією того самого файлу**: посилання й gid не змінюються.
Попередні версії лишаються в Drive → «Керувати версіями».
Клітинки змінюються не напряму, бо це xlsx, а не нативна Google Таблиця, і Sheets API такий файл не редагує.

Одноразове налаштування доступу:
1. https://console.cloud.google.com → створити проєкт → APIs & Services → Library → увімкнути **Google Drive API**.
2. OAuth consent screen → External/Internal → додати свій email у Test users.
3. Credentials → Create credentials → OAuth client ID → **Desktop app** → Download JSON → зберегти як `credentials.json` у цій папці.
4. Перший запуск `python update_crossings.py --drive` відкриє браузер для входу. Після цього `token.json` зберігається, і далі вхід не потрібен.

## Запуск з локальним файлом
```
python update_crossings.py "Калькулятор IMPORT_EXPORT.xlsx"
```
Без параметрів скрипт дозаповнює кожен лист від останнього заповненого дня до завтра (D+1),
а якщо в колонці A ще немає потрібних дат, дописує їх сам.
Опції: `--from 2026-11-01 --to 2026-11-24`, `--overwrite`, `-o новий.xlsx`, `--corridors UA-HU,HU-UA`.

Щоденний запуск (Windows Task Scheduler: `python update_crossings.py --gsheet`) — після ~11:00 за Києвом, коли JAO публікує фінальні результати на D+1.

## Перетини RO / MD (eap-office.ua.energy) — тільки з вашого ПК
Сайт Укренерго блокує запити з-за меж України (і eap-office, і ua.energy), тому ці напрямки
(UA-RO, RO-UA, UA-MD, MD-UA) завантажуються через ваш Chrome:

    py eap.py browser     # відкриє Chrome → «Гість» → Добові → дата → Експорт в Excel (скільки треба дат)
    py eap.py import      # запише всі файли з eap_downloads\ у Google Таблицю

Правило: «Запропонована» (B) > 0 → «Гранична ціна» (E), інакше #DIV/0!.
Перевірити, як розпізнано файл: `py eap.py inspect eap_downloads\файл.xlsx`.
`run_all.py` теж автоматично імпортує нові файли з eap_downloads\.
Під час `browser` усі запити сайту пишуться в eap_capture.json — за ним можна зробити
повністю автоматичне завантаження без кліків.

## Сайт і звіт у Telegram
- `docs/index.html` — сайт із графіками: РДН UA і сусідів, спред, профіль доби, ціни перетинів,
  аналітика (середня, base/peak, мін/макс, волатильність, розмах доби, зміна до попереднього періоду)
  й арбітраж з урахуванням ціни перетину. Період, крок (година/день/місяць/рік), години й валюта обираються вручну.
- `build_site.py` читає Google Таблицю й записує `docs/data.js`, потім пушить на GitHub.
  Локально: `python build_site.py --no-push`, далі відкрийте `docs/index.html`.
- `tg_report.py` надсилає звіт на D+1 із кнопкою «Відкрити сайт» (`--dry-run` лише показує текст).
  Токен береться з `KT_bot/.env` (`TELEGRAM_TOKEN`); `REPORT_CHAT_ID`, `REPORT_THREAD_ID`, `SITE_URL` можна перевизначити там само.
